# 🟣 LAB 7: Publish Your Academic Portfolio

---

# 🎯 LAB OBJECTIVE

> “Make your academic work visible online and convert your repository into a simple portfolio.”

---

# 🎯 PROBLEM WE ARE SOLVING

Faculty often:

* Have valuable work but no online presence
* Share resumes as static PDFs
* Don’t have a structured digital portfolio

---

👉 Result:

* Limited visibility
* Hard to showcase work
* No centralized academic profile

---

# 💡 WHAT THIS LAB WILL ACHIEVE

By the end, participants will:

* Have their work visible on GitHub
* Create a clean README-based profile
* (Optional) Enable a simple website using GitHub Pages

---

# ⏱️ TIME: ~30–40 minutes

---

# 🧪 STEP-BY-STEP INSTRUCTIONS (FOR PARTICIPANTS)

---

## 🧩 Step 1: Open Your Repository on GitHub

* Go to your repo on GitHub

---

## 🧩 Step 2: Edit README.md

Click **README.md → Edit**

Replace content with:

```markdown
# My Academic Portfolio

## 👩‍🏫 Name
Your Name

## 🏫 Department
Your Department

## 📚 Courses Taught
- Course 1
- Course 2

## 🔬 Research Interests
- AI
- Data Science

## 📄 Publications
- Paper 1
- Paper 2

## 📧 Contact
your-email@example.com
```

---

## 🧩 Step 3: Commit Changes (on GitHub UI)

* Click **Commit changes**

---

## 🧩 Step 4: Refresh Repository

👉 You now see a **clean portfolio view**

---

## 🧩 Step 5: Pull Changes Locally

```bash
git pull origin main
```

---

# 🌐 OPTIONAL: ENABLE GITHUB PAGES (MINI WEBSITE)

---

## 🧩 Step 6: Go to Settings

* In repo → **Settings**

---

## 🧩 Step 7: Go to Pages

* Left sidebar → **Pages**

---

## 🧩 Step 8: Configure

* Source: `main` branch
* Folder: `/ (root)`
* Save

---

## 🧩 Step 9: Access Website

👉 GitHub will give a URL like:

```
https://<username>.github.io/my-academic-profile/
```
